# 定义

$\pi(x)$：不超过 $x$ 的素数的 个数。

令 $a = \pi(x^{1/3})$。

$\phi(x, a)$：不超过 $x$ 且没有 $\le p_a$ 的素因子的正整数的个数。  
约定 $\phi(x, 0) = \lfloor x \rfloor$.

$P_2(x, a)$：不超过 $x$，有两个素因子，且素因子都大于 $p_a$ 的正整数的个数。

# 公式

$$
\pi(x) = \phi(x, a) + a - 1 - P_2(x, a).
$$

## 计算 $P_2(x, a)$

$P_2(x, a) = \# \set{n \le x : n = p_b p_c \text{ with } a < b \le c}$.

$n \le x \implies p_b \le \sqrt{x}$

枚举 $b$：$p_b p_c \le x \implies p_c \le x/p_b \implies c \le \pi(x/p_b)$.

$$
p_2(x, a) = \sum_{b = a+1}^{\pi(\sqrt{x})} \pi(x/p_b) - b + 1 = -(a + \dots + \pi(\sqrt{x}) - 1) + \sum_{b = a+1}^{\pi(\sqrt{x})} \pi(x/p_b).
$$

## 计算 $\phi(x, a)$

递归：$\phi(x, a) = \phi(x, a - 1) - \phi(x/p_a, a - 1)$.

所有递归调用都形如 $\phi(x/n, b)$，其中 $n$ 无平方因子，且素因子在 $p_a, p_{a-1}, \dots, p_{b+1}$ 中.

我们用 $(n, b)$ 这两个参数描述一个递归调用。

平凡边界：$(n, 0)$。

LMO 的方法：当 $n > x^{1/3}$ 时停止递归。  
于是他们把 $(n, 0)$ with $n \le x^{1/3}$ 称作**平凡叶子**，把 $(n, b)$ with $n > x^{1/3}$ 称作**特殊叶子**。

### 计算平凡叶子的贡献

对 $[1, x^{1/3}]$ 中的无平凡因子数 $n$ 求 $\mu(n) \lfloor x/n \rfloor$ 的和.

### 计算特殊叶子的贡献

特殊叶子的性质：$(n, b)$ 是特殊叶子 $\iff n = n^{*}p_{b+1}$ with $n^{*} \le x^{1/3} < n^{*}p_{b+1}$.  
特殊叶子 $(n, b)$ 的贡献是 $\mu(n) \phi(x/n, b)$. 注意到 $n > x^{1/3} \implies x/n < x^{2/3}$.

又注意到 $n^{*} \le x^{1/3} < n^{*}p_{b+1} \implies x^{1/3}/p_{b+1} < n^{*} \le x^{1/3}$.

固定 $b$，做下列两步
- 第一步：用 $p_1, \dots, p_b$ 筛 $[1, x^{2/3}]$. 设法支持下述操作
    - 给定整数 $y$ with $0 \le y < x^{2/3}$，查询 $\phi(y, b)$.  
    可以用树状数组来维护序列一个 01 序列 $(f_y)_{1 \le y \le x^{2/3}}$，$f_y$ 表示 $y$ 有没有 $\le p_b$ 的素因子。

- 第二步：对满足下列条件的 $n^{*}$ 求 $\mu(n^{*}p_{b+1}) \phi(x/(n^{*} p_{b+1}))$ 的和。
    - $x^{1/3}/p_{b+1} < n^{*} \le x^{1/3}$
    - $n^{*}$ 无平方因子
    - $n^{*}$ 的最小素因子 $> p_{b+1}$

    注意到 $\mu(n^{*}p_{b+1})$ 即 $-\mu(n^{*})$.
